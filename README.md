# Jonas

Product lead for software and embedded systems in aerospace and defence. I work across the whole range, from programme strategy to the code and the CI pipeline, and I build my own tools along the way. Most of what is below is built with Claude Code as a pair.

[LinkedIn](https://www.linkedin.com/in/jonas-bannasch/)

## Shipped

- **[Defence Brief](https://defence-brief.com)**: a daily digest of defence news with a focus on the Western world, researched, written and published automatically every morning. Python pipeline, static site on Cloudflare Pages.

## In progress

- **dial-in**: an espresso dial-in simulator and game. A physics model of the coffee puck (Darcy flow over 40 cells, channeling, CO2 from bean age, two-pool extraction) written in Rust and compiled to WebAssembly, a Three.js bench with parametrically modelled equipment generated by Blender scripts, and a challenge mode where the bean's properties are hidden and you dial it in from taste and shot time alone. Public release once the branding on the models is stripped.

## Experiments

- **Air-to-air combat simulator**: two AI-controlled fighters with different tactical doctrines fight it out in Three.js. You pick the jets and the tactics, then watch.
- **Chip visualiser**: an interactive 3D explorer of a modern processor for teaching what the blocks on a die actually do.
- **SysML v2 UAV models**: a reference architecture for a notional reconnaissance UAV modelled in SysML v2, with and without a NAF v4 viewpoint, generated and maintained with an LLM in the loop.
- **Jonas OS**: a personal assistant for daily admin built as a thin layer of skills and context files on top of Claude Code, instead of a separate app. Starts with email triage.
