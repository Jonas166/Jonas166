## In progress

- **dial-in**: an espresso dial-in simulator and game. A physics model of the coffee puck in Rust and WebAssembly, a 3D bench with parametrically modelled equipment, and a challenge mode where you dial in an unknown bean from taste and shot time alone.

## Experiments

- **Air-to-air combat simulator**: two AI-controlled fighters with different tactical doctrines fight it out in 3D. You pick the jets and the tactics, then watch.
- **Chip visualiser**: an interactive 3D explorer of a modern processor, for teaching what the blocks on a die actually do.
- **SysML v2 UAV models**: a reference architecture for a notional reconnaissance UAV, modelled in SysML v2 with an LLM in the loop.
- **Jonas OS**: a personal assistant for daily admin, built as a thin layer on top of Claude Code rather than as a separate app.
